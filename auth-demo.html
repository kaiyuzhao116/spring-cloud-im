auth 的其他职责

📝 注册 /register

校验账号密码 → BCrypt 加密 → 调 user 落库 → 自动加管理员好友 → 直接签 token（注册即登录）。

🔄 续签 /renew

拿刚过期的旧票换新票，四重校验：签名、宽限期、是否被踢、账号状态。

🔁 重置密码

管理员重置他人密码，先校验操作者 admin，哈希由 auth 生成（唯一持有密码策略的地方）。

🚪 退出 /logout

目前空实现：无状态 JWT 服务端难以主动作废，靠客户端删 token。

它不做什么（边界）

❌ 不存用户资料

昵称、头像、资料修改在 user 服务。

❌ 不管消息/好友

消息、会话、好友关系在 im 服务。

❌ 不验签

验签是网关的活，auth 只负责签发。
