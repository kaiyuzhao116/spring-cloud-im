# 启动与运行指南

> 目标：从零把整套环境拉起来，能登录、能聊天。
> 全部命令都在项目根目录 `D:\360MoveData\Users\凯宇\Desktop\spring_cloud` 下执行。

---

## 0. 一页速查

### 端口表

| 端口 | 组件 | 说明 |
|---|---|---|
| 3306 | MySQL | 库 `spring_cloud`，root / 123456 |
| 6379 | Redis | 密码空，seq 计数器 |
| 8848 | Nacos | 注册中心 + 配置中心 |
| 5672 / 15672 | RabbitMQ | AMQP / 管理台（guest / guest） |
| 8080 | api-gateway | HTTP 统一入口 |
| 8083 | auth | 登录、签发 token（Dubbo 20881） |
| 8084 | user | 用户资料（Dubbo 20882） |
| 8085 | im | 消息落库 + 拉取（Dubbo 20883） |
| 8089 | ws-gateway | Netty 长连接（Dubbo 20885） |
| 5173 | web | Vue 开发服务器 |

### 启动顺序（不要乱）

```
MySQL → Nacos → Redis → RabbitMQ
   → user → auth → im → api-gateway → ws-gateway
   → web
```

**原因**：后面依赖前面。auth 要连 Nacos 找 user；ws-gateway 要连 Nacos 找 im。

验证：


### 1.4 RabbitMQ

## 2. 后端五个服务

### 2.1 IDE 方式（推荐）

在 IDEA 里分别对下面五个启动类点绿三角，**按顺序、等每个 `Started` 再下一个**：

| 顺序 | 启动类 | 启动成功标志 |
|---|---|---|
| 1 | `com.song.user.UserApplication` | `Started UserApplication` |
| 2 | `com.song.auth.AuthApplication` | `Started AuthApplication` |
| 3 | `com.song.im.ImApplication` | `Tomcat started on port(s): 8085` + `Started ImApplication` |
| 4 | `com.song.apigateway.ApiGatewayApplication` | `Started ApiGatewayApplication` |
| 5 | `com.song.wsgateway.WsGatewayApplication` | `Netty 已启动 port=8089` + `Started WsGatewayApplication` |

**不需要加 `--spring.profiles.active=local`**，因为 Nacos 已经在跑。只有想脱离 Nacos 单跑某个模块时才加。

启动前先确认没有旧进程占端口：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 8080,8083,8084,8085,8089 -ErrorAction SilentlyContinue |
  ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
```

### 2.2 命令行方式（可选）

```powershell
cd "D:\360MoveData\Users\凯宇\Desktop\spring_cloud"
mvn -DskipTests install          # 首次或改了代码后必须执行

java -jar user\target\user-0.0.1-SNAPSHOT.jar
java -jar auth\target\auth-0.0.1-SNAPSHOT.jar
java -jar im\target\im-0.0.1-SNAPSHOT.jar
java -jar api-gateway\target\api-gateway-0.0.1-SNAPSHOT.jar
java -jar ws-gateway\target\ws-gateway-0.0.1-SNAPSHOT.jar
```

> 改了 `spring-cloud-api`（契约模块）后，必须重新 `mvn install`，否则 im / ws-gateway 用的还是旧契约。

## 4. 一键自检

```powershell
$ports = @{
  3306='MySQL'; 6379='Redis'; 8848='Nacos'; 5672='RabbitMQ'
  8080='api-gateway'; 8083='auth'; 8084='user'; 8085='im'; 8089='ws-gateway'; 5173='web'
}
$ports.GetEnumerator() | Sort-Object Name | ForEach-Object {
  $c = Get-NetTCPConnection -State Listen -LocalPort $_.Name -ErrorAction SilentlyContinue
  if ($c) { "OK   {0,-14} {1}" -f $_.Value, $_.Name } else { "FAIL {0,-14} {1}" -f $_.Value, $_.Name }
}
```

十个都 OK 才算齐全。

## 7. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `NacosException: Client not connected` | Nacos 没起 / 8848 被占 | 启动 Nacos，确认 8848 |
| `Port 8080 was already in use` | 旧进程没退 | 用第 2.1 节的命令杀端口 |
| 登录 401 | 账号密码错 | 用 `admin / 123456` |
| 登录 429 | 密码错 5 次被锁 15 分钟 | `redis-cli del auth:fail:admin` |
| ws 连不上，`server rejected` | token 过期（30 分钟） | 重新登录 |
| 消息发出去了，对方没收到 | RabbitMQ 没起 / im 没连上 | 看 ws-gateway 日志有没有 `推送消息 ... 命中连接数` |
| 前端一直「连接中」 | ws-gateway 没起（8089） | 启动 ws-gateway |
| 改了 api 契约但没生效 | 没重新 `mvn install` | 重新 install 并重启服务 |

## 8. 数据在哪 / 怎么重置

| 数据 | 位置 |
|---|---|
| 用户、消息、会话卡片 | MySQL `spring_cloud`（`sys_user` / `im_message` / `im_conversation_member`） |
| seq 计数器 | Redis `im:seq:{conversationId}` |
| 登录失败计数 | Redis `auth:fail:{account}` |
| MQ 交换机与队列 | RabbitMQ（临时队列随 ws-gateway 关闭自动删除） |

重置聊天数据：

```sql
DELETE FROM im_message;
DELETE FROM im_conversation_member;
ALTER TABLE im_message AUTO_INCREMENT = 1;
```

```powershell
& "D:\360MoveData\Users\凯宇\Desktop\redis\redis-cli.exe" -p 6379 --scan --pattern "im:seq:*" |
  ForEach-Object { & "D:\360MoveData\Users\凯宇\Desktop\redis\redis-cli.exe" -p 6379 del $_ }
```
